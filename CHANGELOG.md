# Gamem 3.1.0 is out!

_You can download it on [NuGet](https://www.nuget.org/packages/Gamem)!_

## New methods

- **GetAngleToTarget** - Calculates the angle in radians from a starting point to a target point in 2D space
- **CheckSegmentVsSegment** - Determines whether two 2D line segments intersect each other
- **CalculateCentripetalAcceleration** - Calculates the centripetal acceleration of an object moving along a circular path
- **Slerp** - Performs spherical linear interpolation (Slerp) between two 3D unit vectors represented by individual components
- **CalculateTimeToApex** - Calculates the time required for a projectile to reach the apex (highest point) of its trajectory under constant gravity
