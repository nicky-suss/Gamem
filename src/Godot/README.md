# Gamem extension for Godot (supports vectors)

**Extension for [Gamem](https://www.nuget.org/packages/gamem) that provides work with vectors (Vector2, Vector3) in Godot**

## 🛍️ Installation
```
dotnet add package Gamem.Godot
```
