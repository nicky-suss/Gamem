# Gamem extension for Stride (supports vectors)

**Extension for [Gamem](https://www.nuget.org/packages/gamem) that provides work with vectors (Vector2, Vector3) in Stride**

## 🛍️ Installation
```
dotnet add package Gamem.Stride
```
