# Gamem extension for MonoGame (supports vectors)

**Extension for [Gamem](https://www.nuget.org/packages/gamem) that provides work with vectors (Vector2, Vector3) in MonoGame**

## 🛍️ Installation
```
dotnet add package Gamem.MonoGame
```
