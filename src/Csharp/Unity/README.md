## 1.0.0-preview
This package is not ready for production use yet. It was built to test it in Unity Engine and contains one method only. Wait until `1.0.0` comes out (if it works properly)

## Gamem extension for Unity (supports vectors)

**Extension for [Gamem](https://www.nuget.org/packages/gamem) that provides work with vectors (float2, float3) in Unity**

## Installation
```
dotnet add package Gamem.Unity
```
